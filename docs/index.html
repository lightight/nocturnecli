Not a chatbot. A working toolchain.

Nocturne Code drives a real toolset against your project and feeds the actual results back into the conversation. No hallucinated output, no copy-paste relay.

Reads & edits your files
Opens files, makes precise targeted edits, and writes new ones, with every change shown as a diff-style confirmation before anything touches disk.
Runs commands
Executes in your working directory and feeds the real output back.
Searches the codebase
Regex search and directory listing, so it learns structure first.
Takes pasted images
Ctrl+V a screenshot, or reference an image path inline.
One static binary
macOS, Linux, and Windows, on amd64 and arm64. No runtime to install.

One command away

Pick your platform. The installer fetches a prebuilt binary and falls back to building from source if you have Go.

$ curl -fsSL https://nocturnecode.lol/install.sh | sh
PS> irm https://nocturnecode.lol/install.ps1 | iex
$ git clone https://github.com/lightight/nocturnecli && cd nocturnecli $ make install # → ~/.local/bin/nocturne

Then launch it. No environment variables to set:

$ nocturne

Inside the app, run /key noct_your_key once. Your key is saved privately on your machine (~/.config/nocturne) and reused for every project, with no export and no per-folder .env.

Default model is navy:gpt-5.5 — see the models it knows.

Only a vision model sees an image directly. On the rest the image still attaches — Nocturne has a vision model describe it first, preferring navy:claude-haiku-4.5, then sends that description along as text.

Model access is per-account, so use an id you've been granted. Switch any time with /model <id>, or -m on the command line for a single run.

Slash commands

Everything you need without leaving the prompt.

/helpShow every command.
/model [id]Pick a model from a list, or set one by id.
/levelThinking effort: off, normal, or extended.
/permissionsHow tool actions get approved: ask, auto, or bypass.
/key [noct_…]Save your API key privately, remembered across every project.
/image <path>Attach an image (a file path, or Ctrl+V from the clipboard).
/cd <dir>Change the working directory.
/usageUsage dashboard — status, usage & stats.
/coworkComputer use — let it see and control this computer.
/compactSummarize the conversation to free up context.
/resumeResume a saved chat from this directory.
/newStart a new chat.
/remoteControl this session from your browser, paired & end-to-end encrypted.
/clearClear the conversation.
/initGenerate a NOCTURNE.md for the project.
/updateUpdate Nocturne Code to the latest release.
/exitQuit.

A clean agent loop

The model asks for a tool, Nocturne Code runs it for real, and the result flows back, looping until the task is done.

  1. You asknatural language
  2. Model calls a toolread · edit · run
  3. Nocturne Code executeson your machine
  4. Result loops backuntil finished
